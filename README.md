# ResumeIQ

### Cloud-Based Intelligent Resume Compression and ATS Optimization System

## Overview

ResumeIQ is a research prototype designed to improve resume readability and ATS compatibility through intelligent parsing, semantic compression, and job-description matching.

## Key Modules

1. Resume Ingestion
2. Resume Parsing
3. Semantic Compression
4. ATS Optimization
5. Template Rendering

## Technology Stack

- Python
- Streamlit
- Tesseract OCR
- spaCy / NER
- TextRank
- BART / T5
- TF-IDF
- Sentence-BERT
- Docker
- Cloud Storage

## Evaluation Parameters

- Parsing Accuracy
- Keyword Coverage
- Semantic Score
- Compression Ratio
- Fact Retention
- Processing Latency

## Project Status

Initial research prototype. Processing modules and experimental evaluation are planned for future development.
